Bottom Tab Bar

StudyBuddy SRL uses a persistent 4-tab bottom navigation bar — Home, Study, Analytics, and Profile — allowing users to switch between primary sections from any screen. The active tab is highlighted with the brand colour and an indicator dot, following Norman's principle of Visibility of System Status to always show the user where they are in the application.
